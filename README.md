# Python4Dynamo

Python scripts from my YouTube videos. Each folder matches a video, and the Dynamo is not Dead series has one folder per episode.

Copy the script into a Python Script node in Dynamo, or open the matching graph from the video. Each episode folder has its own README that says which node each script goes in.
